# Cuky Pastelería: tienda virtual

## Objetivo de la aplicación
Desarrollar una tienda virtual para Cuky Pastelería que permita consultar el catálogo de postres, controlar el inventario y promover las ventas mediante ofertas y recomendaciones de productos.

## Público objetivo
Personas de Arequipa que compran tortas, cupcakes, galletas y helados para cumpleaños, aniversarios y reuniones familiares, en su mayoría jóvenes y adultos que usan el celular para hacer sus pedidos por WhatsApp.

## Características clave
- Diseño responsivo que se adapta a celular, tablet y computadora.
- Catálogo con búsqueda, filtro por categoría y orden por precio o descuento.
- Inventario con stock mínimo, alertas de stock bajo y registro de entradas y salidas.
- Descuentos por producto, sección de ofertas con cuenta regresiva y código promocional.
- Recomendaciones de productos más vendidos y relacionados por categoría.
- Libro de Reclamaciones virtual guardado en la base de datos.

## Tecnologías
ReactJS con Vite y Tailwind CSS en el frontend. Django REST Framework en el backend.
